Repositorio pensado para verificar resultados de los métodos numéricos estudiados durante la cursada de 2026.

## ✨ ¿Qué es este proyecto?

Este espacio está orientado a organizar y documentar ejercicios, cálculos y validaciones relacionadas con:

- resolución de ecuaciones no lineales
- interpolación y aproximación
- sistemas de ecuaciones lineales
- diferenciación e integración numérica
- métodos iterativos y análisis de error

La idea es que sirva como referencia práctica para comparar resultados y reforzar la comprensión de cada método.

## 🎯 Objetivo

- consolidar conceptos vistos en clase
- verificar resultados mediante cálculos y pruebas
- mantener un repositorio ordenado para estudiar y revisar temas clave
- facilitar la práctica de métodos numéricos con ejemplos claros

## 📚 Estructura del repositorio

Actualmente el repositorio se encuentra en etapa inicial, pero está preparado para crecer con:

- ejercicios resueltos
- algoritmos implementados
- comparaciones entre métodos
- notas de análisis y validación

## 🚀 Cómo usar este repositorio

1. Cloná el proyecto:
   ```bash
   git clone https://github.com/abregu081/UTN---Calculo-Metodos.git
   ```
2. Entrá a la carpeta:
   ```bash
   cd UTN---Calculo-Metodos
   ```
3. Explorá los archivos y documentá los resultados de cada ejercicio o método numérico que resuelvas.

## 🧠 Enfoque académico

La materia de métodos numéricos busca encontrar soluciones aproximadas a problemas complejos mediante estrategias computacionales eficientes y confiables. Este repositorio acompaña ese proceso, promoviendo la verificación, comparación y análisis crítico de resultados.

## 📌 Nota

Este proyecto está pensado como un repositorio académico y de estudio. A medida que avance la cursada, se irán incorporando más contenido y ejercicios.
